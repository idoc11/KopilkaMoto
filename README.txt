КОПИЛКА НА МОТОЦИКЛ — мобильное веб-приложение

СОДЕРЖИМОЕ
- index.html — приложение
- manifest.webmanifest — настройки установки
- service-worker.js — офлайн-режим
- icon.svg — иконка

КАК УСТАНОВИТЬ НА ANDROID
1. Размести все файлы из этой папки на одном HTTPS-хостинге (например, GitHub Pages).
2. Открой опубликованный HTTPS-адрес в Chrome на телефоне.
3. Нажми «Установить приложение» (если кнопка появилась) или меню ⋮ → «Установить приложение» / «Добавить на главный экран».
4. После первого открытия приложение сможет запускаться без интернета.

ВАЖНО
- Нельзя установить PWA прямо из HTML-файла, открытого как file://. Для установки нужен HTTPS-сайт или локальный сервер.
- Данные сохраняются в хранилище браузера на этом устройстве. Они не синхронизируются между телефонами.
- Используй «Скачать резервную копию» в настройках. При переносе на другой телефон открой приложение и выбери «Восстановить из копии».
- Существующий план, даты, цель и расчёты исходного трекера сохранены.
