# KopilkaMoto v5 — отчёт проверок

Дата проверки: 15.11.2026.

## Проверено успешно
- JavaScript приложения: `node --check`.
- HTML: 56 уникальных ID; все 51 статические обращения к ID существуют.
- Основные сценарии логики в изолированном JS runtime: добавление дохода, добавление расхода, итоговый баланс, фильтрация истории, сохранение цели и темы.
- Валидация: отклоняются суммы меньше 1 ₽ и операции с будущей датой.
- Миграция: корректная старая запись сохраняется, повреждённая отбрасывается; некорректные настройки нормализуются.
- График формирует 7 последних календарных дней.
- AI Worker: CORS preflight, блокировка чужого Origin, проверка Content-Type, ограничение размера тела, успешный ответ и изоляция системной инструкции от пользовательского контекста.
- Service Worker удаляет только старые кеши с префиксом `kopilkamoto-`, не затрагивая кеши других приложений на том же домене.
- `manifest.webmanifest` проходит JSON parse.

## Ограничения проверки
Полный ручной прогон в реальном браузере и проверка на физических Android/iOS-устройствах не выполнены. Попытка запустить headless Chromium в среде сборки зависла на системном запуске браузера, поэтому браузерный E2E не заявляется. Перед публикацией проверь приложение в своём браузере и сделай JSON-резервную копию.
