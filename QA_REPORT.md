## v6.1: оформление без «нейросетевого» вида

- Эмодзи и юникод-значки (⌂ ✦ ✎ ➤, медали достижений) заменены своими SVG-значками; тест следит, чтобы они не вернулись.
- Типовая тёмная градиентная карточка заменена приборной панелью: крупная сумма шрифтом Russo One (OFL, `fonts/`) и дорога с мотоциклом, который едет к флажку по мере накопления.
- Тёплая палитра «асфальт и разметка», меньше одинаковых карточек и теней.
- Тексты переписаны короче и проще: без «Привет! Я помогу…», «отличная работа!», «Давай настроим…». Отметки показывают, сколько денег не хватает до следующей.
- Помощнику в Worker запрещены вступления вроде «Отличный вопрос», эмодзи и заключения «В итоге».

## v6.2: анимации, прогноз, замок до цели

- Анимации: досчитывание суммы, мотоцикл едет по дороге с бегущей разметкой, рост столбцов графика по очереди, «выпрыгивание» новой отметки с тостом, подсветка новой записи, уход удалённой записи, плавные переходы разделов, тосты, диалоги и сообщения чата, точки «печатает», флажок машет на финише, отклик кнопок при нажатии, короткая вибрация при сохранении (Android).
- Все анимации отключаются при системной настройке «уменьшить движение» (e2e «motion»).
- Прогноз даты покупки по темпу последних 30 дней (unit «темп и прогноз», e2e «прогноз»).
- Замок до цели: подтверждение расхода с 3-секундной задержкой, оценка сдвига покупки в днях, счётчик расходов из копилки (unit «замок», e2e «замок до цели»).
- Помощнику передаются прогноз и темп.

## v6.2.1: медленнее анимации, проверка на ошибки

- Анимации замедлены примерно вдвое (досчитывание суммы 1,5 с, езда мотоцикла 1,6 с). Скорость задаётся в одном месте: переменные `--t-*` в `styles.css` и `MOTION` в `js/motion.js`.

## Принятые риски

| Риск | Почему принят | Чем смягчён |
| --- | --- | --- |
| Данные и переписка с помощником хранятся в `localStorage` без шифрования | Приложение локальное, без аккаунта; шифрование ключом, хранящимся там же, защиты не даёт | Данные не покидают устройство, кроме вопросов помощнику; предупреждение не писать секреты в комментарии |
| Браузер может очистить `localStorage` (Safari, нехватка места) | Свойство платформы | `navigator.storage.persist()`, напоминания о резервной копии, рекомендация установить на экран «Домой» |
| Адрес прокси вводит пользователь, туда уходят цель, баланс и до 80 записей | Это и есть функция помощника; без адреса ничего не отправляется | Только `https:`; явное предупреждение в интерфейсе и README |
| Публичный адрес Worker можно вызывать напрямую в обход `Origin` | Без аккаунтов клиент не может хранить секрет | Лимит по IP, дневной лимит через KV, рекомендация бюджета в кабинете OpenAI |
| Нет проверки на реальных Android/iPhone и развёртывания Worker в Cloudflare | Недоступно из среды разработки | Ручной чек-лист ниже; e2e в Chromium с эмуляцией телефона, Lighthouse |
| Нет офлайн-синхронизации между устройствами | Осознанное ограничение (нет сервера) | Перенос через JSON-копию |

## Что не проверено автоматически

Тесты идут в Chromium. На реальных устройствах перед релизом пройди чек-лист.

### Android (Chrome)
- [ ] Открыть сайт → «Установить приложение» → значок на главном экране без обрезки.
- [ ] Добавить доход и расход, перезапустить приложение — данные на месте.
- [ ] Включить режим полёта → приложение открывается и работает.
- [ ] После публикации новой версии вернуться в приложение → баннер «Доступна новая версия» → «Обновить».
- [ ] «Скачать JSON» → удалить операцию → «Восстановить JSON» → данные вернулись.
- [ ] AI-чат: вопрос, ответ с форматированием, кнопка «Назад» системы.
- [ ] Анимации плавные, не дёргаются на слабом телефоне; вибрация при сохранении.

### iPhone (Safari)
- [ ] «Поделиться» → «На экран Домой»: иконка не скриншот, а знак ₽.
- [ ] Нижняя навигация и тост не залезают под полоску «Домой».
- [ ] Клавиатура суммы — цифровая с запятой.
- [ ] Офлайн-запуск установленного приложения.
- [ ] Восстановление копии через «Файлы».

### Cloudflare Worker
- [ ] `npx wrangler deploy` проходит с `[[ratelimits]]` (нужен Wrangler 4.36+).
- [ ] Седьмой вопрос подряд за минуту получает «Слишком много вопросов подряд».
- [ ] Запрос с другого сайта получает 403.
