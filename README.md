# KopilkaMoto

Мобильное PWA для учёта накоплений на мотоцикл: доходы (доставка и подработки), расходы, план к сроку, достижения и AI-помощник. Работает без аккаунта и офлайн, данные хранятся на устройстве.

Сайт: https://idoc11.github.io/KopilkaMoto/

## Возможности

- Учёт доходов и расходов, часы работы для доставки (`8`, `7:30`, `7,5` или `7 ч 30 мин`), доход в час.
- Цель, стартовая сумма и сроки: сумма «нужно в день», сравнение с линейным планом.
- Фото мотоцикла мечты на главной: сначала серое, цвет проявляется по мере накопления, на 100% — полностью цветное с подсветкой.
- Прогноз даты покупки по темпу последних 30 дней.
- «Замок до цели»: перед расходом из копилки — подтверждение с задержкой и оценкой, на сколько дней он отодвинет покупку; счётчик таких расходов.
- Анимации: сумма досчитывает, мотоцикл едет по дороге, столбцы графика вырастают, новые отметки «выпрыгивают». При системной настройке «уменьшить движение» анимации отключаются.
- График чистого результата за 7 дней (нажми на столбец — увидишь точную сумму), сводка за месяц.
- Отметки прогресса (10%, четверть, половина…) с суммой до следующей и серия дней с доходом.
- История с поиском и фильтрами, экспорт в CSV (защищён от формул Excel).
- Резервная копия JSON: скачать / восстановить с возможностью отмены, напоминания о копии.
- AI-помощник через ваш собственный прокси (Cloudflare Worker); ответы с безопасной разметкой.
- Светлая и тёмная темы, установка на главный экран, офлайн-режим, обновление по кнопке.

## Установка на телефон

- **Android:** Chrome → меню ⋮ → «Установить приложение».
- **iPhone:** Safari → «Поделиться» → «На экран Домой». Установленное приложение лучше защищено от автоматической очистки данных Safari.

## Данные и приватность

- Операции хранятся в `localStorage` этого браузера (ключ `moto-tracker-v1`), синхронизации между устройствами нет.
- Приложение просит браузер не удалять данные (`navigator.storage.persist()`) и напоминает о резервной копии каждые 14 дней или 20 изменений.
- Если какие-то сохранённые записи не удалось прочитать, приложение не удаляет их молча: исходные данные сохраняются отдельно, их можно скачать в «Настройки → Резервная копия».
- Восстанавливаются копии всех прошлых версий (`app: "KopilkaMoto"` и `app: "moto-savings-tracker"`).
- При вопросе AI-помощнику через твой прокси в OpenAI уходят цель, сроки, баланс и до 80 последних операций с комментариями. Не пиши в комментарии пароли и номера карт.

## Публикация (GitHub Pages)

1. GitHub → **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Каждый push в `main` запускает workflow «Публикация на GitHub Pages»: он собирает `_site/` только из файлов приложения и проставляет в service worker хеш коммита, поэтому установленные приложения получат кнопку «Обновить».

## AI-помощник (Cloudflare Worker)

GitHub Pages не может хранить секреты, поэтому ключ OpenAI живёт в Worker (`worker/`).

```bash
cd worker
npx wrangler login
npx wrangler secret put OPENAI_API_KEY     # вставь ключ, он не попадёт в репозиторий
npx wrangler deploy
```

Перед деплоем проверь `worker/wrangler.toml`:

- `ALLOWED_ORIGIN` — точный адрес сайта (`https://idoc11.github.io`), не `*`.
- `OPENAI_MODEL` — по умолчанию `gpt-5-mini`; для reasoning-моделей Worker сам передаёт правильные параметры.
- `[[ratelimits]]` — ограничение 6 вопросов в минуту с одного IP (нужен Wrangler 4.36+). Без биндинга работает запасной лимит в памяти.
- Дневной лимит на весь Worker: создай KV (`npx wrangler kv namespace create USAGE`) и раскомментируй блок `kv_namespaces`.

Затем вставь HTTPS-адрес Worker в «Настройки → AI-помощник». Проверка `Origin` защищает только от чужих сайтов в браузере; от прямых запросов защищают лимиты — не отключай их, а в кабинете OpenAI задай месячный бюджет.

## Разработка

Нужен Node.js 20+.

```bash
npm ci
npm start            # http://localhost:8080 — ES-модули не работают через file://
npm run lint         # ESLint + Prettier
npm test             # unit-тесты, порог покрытия 80% и E2E (Playwright + axe)
npm run build        # сборка _site/ как на GitHub Pages
npm run icons        # перегенерировать PNG-иконки из описания в scripts/icons.mjs
```

Перед первым запуском E2E: `npx playwright install chromium`.

### Структура

| Путь | Назначение |
| --- | --- |
| `index.html`, `styles.css` | Разметка и стили, без инлайн-кода (строгая CSP) |
| `js/core.js` | Вся логика: расчёты, миграция данных, CSV, копии, контекст для AI |
| `js/storage.js` | Работа с `localStorage`, сохранение исходных данных |
| `js/markdown.js` | Безопасный рендер ответов AI |
| `js/motion.js` | Анимации (с учётом «уменьшить движение») |
| `js/app.js` | Интерфейс |
| `service-worker.js` | Офлайн-кеш и обновления |
| `fonts/` | Шрифт Russo One (лицензия OFL, `fonts/OFL.txt`) |
| `worker/` | Cloudflare Worker для AI |
| `tests/unit`, `tests/e2e` | Тесты |
| `docs/AUDIT.md` | Исходный аудит, по которому делалась версия 6 |

### Своё фото мотоцикла

Положи фото на белом фоне и запусти (нужны Python 3, Pillow и numpy):

```bash
python3 scripts/cutout.py фото.jpg images/dream-bike.webp
```

Скрипт уберёт белый фон (в том числе между спицами), сделает мягкую тень и сожмёт картинку до 800 px. Потом подними версию (см. ниже), чтобы установленные приложения получили новую картинку.

### Выпуск новой версии

1. Подними `version` в `package.json` и `APP_VERSION` в `js/app.js` (тест проверяет, что они совпадают).
2. При публикации не через Actions — смени `VERSION` в `service-worker.js`.
3. `npm run lint && npm test`.
