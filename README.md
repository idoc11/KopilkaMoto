# KopilkaMoto — версия 5

Мобильный PWA-трекер накоплений на мотоцикл. Работает без аккаунта и хранит данные локально в браузере.

## Что улучшено в этой версии
- Восстановление и чтение старых данных с проверкой структуры, дат (включая запрет будущих дат), сумм и типов операций.
- Защита импорта JSON от некорректных файлов и чрезмерно больших резервных копий.
- Исправлен график: теперь он показывает именно последние 7 календарных дней.
- Поиск в истории учитывает тип операции.
- Тайм-аут AI-запроса, защита от повторной отправки и сокращённый состав передаваемых данных.
- AI-прокси проверяет тип и размер запроса; контекст операций явно обозначен как недоверенные данные.
- Настраиваемые дата начала и дедлайн накоплений.
- Ежедневная сумма для достижения цели и сравнение с линейным планом.
- График чистого результата за последние 7 дней: доходы минус расходы.
- Сводка текущего месяца: доходы, расходы и чистый итог.
- Редактирование операций, поиск и фильтры истории.
- Экспорт истории в CSV и резервная копия/восстановление JSON.
- Проверка дат, сумм и часов; защита от потери изменений при ошибке записи в хранилище.
- Сохранена совместимость с прежним ключом `moto-tracker-v1`.
- Достижения за прогресс цели, количество операций и активные дни с доходом.
- Серия дней с доходом и подсказка о следующем достижении.
- Экспорт CSV дополнительно защищён от формул в текстовых полях.
- Обновлён кеш Service Worker, чтобы установленное PWA подхватило новую версию.

## Публикация GitHub Pages
1. Распакуй архив и загрузи содержимое папки `KopilkaMoto` в корень репозитория `idoc11/KopilkaMoto` в ветку `main`, сохранив `.github`.
2. GitHub → Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Открой Actions и дождись успешного запуска workflow публикации.
4. Сайт: https://idoc11.github.io/KopilkaMoto/

## Установка
- Android: Chrome → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- iPhone: Safari → «Поделиться» → «На экран Домой».

## Данные и приватность
Данные накоплений хранятся в `localStorage` текущего браузера. Автоматической синхронизации между устройствами нет. Для переноса скачай JSON-копию. Если используешь AI-помощника, вопрос, цель, баланс и до 80 последних операций передаются через указанный прокси в OpenAI для формирования ответа. Не записывай в комментарии пароли, номера карт и другие секреты.

## ChatGPT API
GitHub Pages не может безопасно хранить API-ключ. `ai-worker.js` предназначен для Cloudflare Workers:
1. Создай Worker и вставь содержимое `ai-worker.js`.
2. Добавь Secret `OPENAI_API_KEY`.
3. Добавь переменную `ALLOWED_ORIGIN=https://idoc11.github.io`. Не используй `*`.
4. При необходимости добавь `OPENAI_MODEL` (по умолчанию `gpt-4o-mini`).
5. Опубликуй Worker и укажи его HTTPS URL в настройках приложения.
6. Создай в Cloudflare Rate Limiting rule для Worker (ограничь частоту запросов с одного IP). Проверка `Origin` нужна для CORS, но сама по себе не защищает публичный Worker от прямых запросов и не заменяет ограничение частоты.

Использование API может тарифицироваться отдельно. Не размещай ключ в HTML/JS или GitHub.
